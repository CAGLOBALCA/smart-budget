# Smart Budget Planner – companion app (BETA)

A free, client-side web app for the *Smart Budget Planner* paper notebook. Photograph a page and the app reads the handwritten digits and checkboxes **on your device**. Review and correct the values, then export them to Excel (.xlsx).

- No account, no subscription, no server. Data stays in your browser (localStorage).
- Works offline after the first visit (service worker).
- UI in English, Spanish and Arabic (`?lang=en|es|ar`).
- The handwriting recognition is a small neural network trained on MNIST (~95% per digit on simulated photos). **Always review the values before exporting.**

Live: https://caglobalca.github.io/smart-budget/
